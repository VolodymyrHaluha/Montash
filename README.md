# Montash

Автономний Android-додаток для монтажних робіт на основі [Mounter](https://github.com/VolodymyrHaluha/Mounter). ApplicationId, namespace та Kotlin-пакети — `com.frop.montash`. Баз даних, серверів і бізнес-інтеграцій немає.

## Об'єкти та вироби

- «Об'єкти» — таблиця: **Назва, Опис, К-сть виробів, Статус**. Фото виробів на цій сторінці не відображаються. Назву та опис об'єкта можна змінити через «Редагувати об’єкт» після його відкриття.
- Усередині об'єкта — таблиця **Фото виробу, Назва, Опис, Статус**. Фото відсутнє або недоступне — показується `app/src/main/res/drawable-nodpi/icon.png`.
- Вкладка «Вироби» показує таку саму таблицю виробів з усіх об'єктів. Рядок відкриває дані конкретного виробу.
- У виробі доступні назва, опис, статус, фото, примітка, медіа та голосові записи. Колишні «Характеристики» читаються як «Опис» без втрати тексту.
- «Додати виріб» закріплено в заголовку вибраного об'єкта; новий виріб одразу відкривається для редагування.

Новий виріб має статус **Чернетка**. Його можна змінити на **В процесі** або **Виконано**. Статус об'єкта — найчастіший статус його виробів. За рівності кількості перевага надається менш завершеному стану: Чернетка → В процесі → Виконано. Порожній об'єкт — Чернетка.

## Медіа й голос

«Додати медіа» дозволяє вибрати кілька зображень (зокрема GIF), відео й аудіофайлів. Вкладення копіюються у приватне сховище додатка й відкриваються вбудованим переглядачем; підтримка конкретного кодека залежить від версії Android і пристрою. GIF відтворюються анімовано; відео й аудіо мають елементи керування. Фото також можна зробити системною камерою.

«Записати голос» запитує доступ до мікрофона й починає локальний запис. «Зберегти запис» додає голосове повідомлення до поточного виробу. Є таймер запису. При переході додатка у фон запис завершується і зберігається; незавершений запис під час виходу з екрана скасовується. Відмова в дозволі не блокує інші функції. Вкладення можна видаляти.

Прикріплення й перегляд PDF-креслень видалені. Старі PDF-файли не видаляються автоматично, їхня стара метаінформація зберігається для сумісності, але функції роботи з ними в інтерфейсі немає.

## Дані

Об'єкти, вироби, статуси й посилання на медіа зберігаються у `objects.json`; довідник замовників — у SharedPreferences; фото, медіа та голос — у приватних папках на пристрої. Автоматичне резервне копіювання вимкнено. Очищення даних або видалення додатка видалить локальні записи та вкладення. Вкладки бригади немає.

Додаток не має INTERNET або NFC. Системні камера й вибір файлів збережені за вимогою користувача. RECORD_AUDIO запитується тільки для голосового запису.

## Запуск

Відкрити корінь **Montash**, де є `settings.gradle.kts`, в Android Studio, сумісній з AGP 9.3. Потрібні JDK 21 та Android SDK Platform 37.1; Gradle 9.5.0 wrapper включено. Після Gradle Sync вибрати стандартну конфігурацію **app**, пристрій Android 7/API 24 чи новіший і натиснути Run.

Якщо Module порожній, перевірити помилку Gradle Sync, версію Android Studio, Gradle JDK і локальний шлях до SDK. Закрити проєкт і повторно відкрити корінь Montash після оновлення налаштувань IDE.

```sh
./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
./gradlew connectedDebugAndroidTest
```

Друга команда потребує пристрою або емулятора. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Для першого завантаження залежностей потрібен інтернет; додаток працює локально. [Історія перенесення та перевірки](docs/migration.md).
